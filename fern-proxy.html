Fern Proxy

Play the game · Source in this repo

What it is: Fern proxy is a PostgreSQL proxy. It sits between an app and a database and masks sensitive columns in query results. It is not a web proxy, so it can't unblock websites or games. It also needs a server or Docker, so it can't run on GitHub Pages.

Run it (Docker)

This starts a Postgres database, Fern proxy in front of it, and a psql client.

git clone https://github.com/pebbleford/gnmath.git
cd gnmath/fern-proxy/examples
docker-compose up

In a second terminal, connect through the proxy (port 30000, TLS is not supported yet):

docker exec -it postgres-client psql \
  'postgresql://root:testpassword@fern-proxy:30000/testdb?sslmode=disable'

Run a query such as \dS+;. The columns Owner, Name and Access method come back as ****.

Run it (Rust, no Docker)

cd fern-proxy
make run     # release build; see `make help` for everything else

Then point your Postgres client at the proxy's port instead of the database's own port.

Choose what gets masked

Edit fern-proxy/examples/config.toml:

[masking]
strategy = 'caviar-preserve-shape'   # or 'caviar' (fixed length)

[masking.exclude]
columns = ['*']                      # leave everything alone...

[masking.force]
columns = ['email', 'ssn', 'card']   # ...except these

Use it with your own app

  1. Run your Postgres server as usual.
  2. Run Fern proxy and configure it to forward to that server.
  3. Change your app's connection string to the proxy's host and port.

The upstream project says it is not ready for production. Use it for demos and experiments.
